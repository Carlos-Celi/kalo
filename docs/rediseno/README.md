# Rediseño «Sala de estudio»

Nueva identidad visual de Kalo, pensada para un público de gym y fitness: un estudio de entrenamiento en penumbra donde la luz detrás de calorías y proteína crece con el avance real.

| Archivo | Qué es |
|---|---|
| [`guia.md`](guia.md) | Guía del rediseño: principios, color, tipografía, luz de sala, estado por forma, componentes, mascota, pantallas, movimiento y accesibilidad. |
| [`implementacion.md`](implementacion.md) | Instrucciones paso a paso para la web y Flutter, con pruebas y criterios de aceptación. |
| [`pantallas/propuesta.html`](pantallas/propuesta.html) | Propuesta completa en una sola página (se abre en el navegador). Incluye un Inicio interactivo. |
| [`pantallas/*.png`](pantallas/) | Capturas a 2×: Inicio (arriba y desplazado), Registros, Resultado de la IA, Asistente, Progreso, Acceso y Escritorio. |

Decisión: [ADR 0010](../tecnica/decisiones/0010-rediseno-sala-de-estudio.md). Producto: [`PRODUCT.md`](../../PRODUCT.md).

Todas las cifras de las pantallas son datos de ejemplo (1.850 kcal, 140 g de proteína, 78 kg).
